Карта портов и районов добычи ВБР

2140 портов (точные координаты) и 21 промысловый район/подзона Дальневосточного рыбохозяйственного бассейна — границы 20 из 21 района уточнены по данным ведомственной системы мониторинга рыболовства (ЦСМС, globus.cfmc.ru); для 1 района официальная граница ЦСМС не найдена, показана граница по тексту приказа Минсельхоза России № 285 от 06.05.2022. Отдельными слоями — запретные зоны промысла и полный каталог промысловых зон ЦСМС по всему миру (с фильтром по категориям) по тем же данным.

Слой «Районы вылова (ДВ)» — 21 промысловый район/подзона/подрайон Дальневосточного рыбохозяйственного бассейна по Приложению № 1 к Правилам рыболовства для ДВ бассейна (приказ Минсельхоза России от 06.05.2022 № 285); границы упрощены до прямых линий по опорным точкам приказа — для точных координат обращайтесь к тексту документа (раздел «Документы» на этой странице). Слой «Все районы (справочник)» — укрупнённые границы районов ФАО/морей для всех 394 кодов справочника «Районы добычи ВБР» (включая зарубежные зоны, например Гавайские острова); эти границы приблизительные и показывают только общий океанический/морской район, а не точный контур конкретного кода.
